부산센터 D-HUB 좌석 예약 시스템
v1.0.0 릴리스 2026. 07. 27 www.asm-dhub.fkii.space

개요

부산센터 D-HUB 개발공간(48석)을 연수생이 웹·모바일에서 직접 예약·관리하는 서비스입니다. 실시간 좌석 현황, 명단 기반 가입 통제, 센터 네트워크 접근 제한, 관리자 운영 도구를 갖춘 정식 버전으로 출시합니다.

주요 기능

좌석 예약 · 관리 Core

  • 48석 실시간 좌석도 — 예약 가능·사용 중·자리비움·내 예약·선택됨·사용 불가 6단계 색상 구분
  • “지금부터” 예약: 30·60·90·120분 프리셋 + 10분 단위 세부 조정
  • 연장(종료 1시간 전, 2시간 1회) · 취소 · 자리 변경(시간 유지, 좌석만 이동)
  • 자리비움 표시 후 20분 미복귀 시 자동 취소

접근 통제 · 가입 Security

  • Google 계정 로그인(OAuth)
  • 연수생 명단(팀·이름) 대조 가입 — 동일 명단 1회 사용으로 1인 다계정 방지
  • 사무국 직원 예외 가입 처리
  • 센터 Wi-Fi(공인 IP) 접속 시에만 예약 가능 — 외부 접속 차단

관리자 기능 Admin

  • 좌석 점검 잠금 — 점검·공사 시 해당 좌석 예약 차단
  • 연수생 명단 관리 — 추가·삭제·검색, 가입 현황, 계정 연결 해제
  • 신고 처리(처리 전/완료) · 좌석 이용 이력 조회
  • 사용자 관리자 권한 지정·해제

신고 · 의견 Ops

  • 유형별 접수: 자리 이용 · 시설 고장 · 기타 의견
  • 무단 사용 신고 시 대상 좌석·이용자 정보 자동 기록
  • 운영시간(08–20시) 외에도 좌석 현황은 상시 열람 가능
  • PC · 모바일 반응형 지원

예약 정책

예약 가능 시간08:00 – 20:00 (그 외 시간은 예약 없이 자유 이용)
예약 단위10분
최대 이용 시간2시간 (연장 2시간 1회, 종료 1시간 전부터)
동시 보유1인 1건
재예약 쿨다운같은 자리 20분 제한 (10분 이내 취소는 예외)
자리비움20분 초과 시 자동 취소
