@@자리요

부산센터 D-HUB 좌석 · 회의실 예약 시스템
v1.1.0 릴리스 2026. 09. 06 www.asm-dhub.fkii.space

개요

정식 출시(v1.0.0) 이후 운영 현장의 요구를 반영해 기능을 크게 넓혔습니다. 예약 알림(웹 푸시), 이용 분석 대시보드, 회의실 예약 현황 조회, 팝업/배너 공지·사용 가이드, 연수생 명단 운영 도구가 더해졌고, 예약 규칙도 현장에 맞게 정교해졌습니다.

이번 버전 주요 기능

예약 알림 (웹 푸시) New

  • 앱을 닫아둬도 기기 OS 알림으로 도착 (PC·모바일 각각)
  • 자리비움 복귀 경고 · 연장 가능 · 종료 임박 · 자동취소 4종
  • 서버가 매분 발송 대상을 판정 — 중복 없이 1회만
  • 아이폰은 홈 화면에 추가 후 수신(앱이 안내)

이용 분석 New

  • 요일별 이용 인원 · 하루 평균 · 현재 이용 중
  • 이용 시간 순위 TOP 5 · 시간대별 평균 점유율
  • 좌석별 이용률 · 예약 시간 분포 · 종료 유형
  • 기간 필터(전체 / 최근 7·30일 / 직접 지정)

회의실 현황 조회 New

  • 18F 회의실 7개(M1~M3 / A1~A4)의 하루 일정
  • 예약 현황 엑셀 업로드 → 배치도 · 타임라인으로 조회
  • 서버 저장으로 관리자끼리 공유(조회 전용)
  • 진행 중 · 예정 · 종료와 이용 가능 시간 한눈에

공지 · 가이드 · 명단 도구 Upd

  • 팝업/배너 공지 — 로그인 팝업 + 사이드바 배너(한 화면 관리)
  • 사용 방법 가이드 페이지
  • 연수생 명단에 누적 이용 시간 표기 · 엑셀 다운로드

예약 규칙 (현행)

예약 가능 시간08:00 – 20:00 (그 외 시간은 자유 이용)
예약 단위10분 · 1인 1건
기본 이용최대 3시간 (프리셋 30·60·120·180분)
연장종료 1시간 전부터 3시간 1회 (최대 6시간)
자리비움20분 초과 자동취소 · 예약당 2회까지
좌석 반납 / 취소10분 넘게 쓰면 반납, 이내면 취소
재예약 쿨다운같은 자리 20분 (10분 이내 취소는 예외)
