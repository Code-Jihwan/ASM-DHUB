@@자리요

부산센터 D-HUB 좌석 · 회의실 예약 시스템
v1.2.0 릴리스 2026. 09. 07 www.asm-dhub.fkii.space

개요

v1.1.0에서 선보인 회의실 현황 조회를, 이번 버전에서 담당자 손을 거치지 않고 자동으로 최신화합니다. 상시 가동 PC가 예약 시스템에서 하루 5회(09·12·15·18·21시) 당일 예약 현황을 받아 자리요에 반영하며, 매 실행마다 새로 로그인해 세션 만료 걱정이 없습니다. 관리자 수동 업로드는 폴백으로 그대로 유지됩니다.

이번 버전 주요 기능

회의실 현황 자동 동기화 New

  • 예약 시스템에서 당일 예약 현황을 자동 수집해 반영
  • 하루 5회 09·12·15·18·21시 — 하루 중 예약 추가·취소도 갱신
  • 서버 공유 스냅샷이라 관리자 누구나 최신 현황을 봄
  • 담당자 수동 업로드 불필요 (필요 시 수동 업로드도 그대로 가능)

안정적인 무인 로그인 New

  • 매 실행마다 새 세션으로 로그인 → 쿠키·세션 만료 문제 없음
  • 사전확인 → 로그인 → 후속 폼 자동 제출까지 실제 흐름 재현
  • 내려받은 파일이 정상 엑셀인지 검사 후에만 반영
  • 상시 가동 PC의 작업 스케줄러로 무인 실행

회의실 현황 조회 다듬기 Upd

  • 예약이 0건인 날도 정상 표기(빈 현황으로 갱신)
  • 18F 외 회의실(SPACE S·하이스퀘어·하이텐 등) 자동 제외
  • 배치도 + 09~24시 타임라인으로 진행·예정·종료 한눈에

수신 · 저장 안정성 Upd

  • 수신 엔드포인트를 시크릿 헤더로 보호
  • 서버에서 18F·하루치만 파싱해 저장(오염·과대 방지)
  • 스냅샷 기록은 서버 전용 키로만 — 조회는 관리자 전용

예약 규칙 (현행)

예약 가능 시간08:00 – 20:00 (그 외 시간은 자유 이용)
예약 단위10분 · 1인 1건
기본 이용최대 3시간 (프리셋 30·60·120·180분)
연장종료 1시간 전부터 3시간 1회 (최대 6시간)
자리비움20분 초과 자동취소 · 예약당 2회까지
좌석 반납 / 취소10분 넘게 쓰면 반납, 이내면 취소
재예약 쿨다운같은 자리 20분 (10분 이내 취소는 예외)
