@@자리요

부산센터 D-HUB 좌석 · 회의실 예약 시스템
v1.3.0 릴리스 2026. 09. 13 www.asm-dhub.fkii.space

개요

관리자만 보던 회의실 현황을 연수생 전체에 공개합니다. 이제 누구나 사이드바에서 18F 회의실의 오늘 일정을 열어 예약 없는 빈 회의실을 바로 찾을 수 있습니다. 함께, 이용 분석의 요일별 이용 인원을 한눈에 읽히는 스탯 레일 + 가로 막대 구성으로 개편했습니다.

이번 버전 주요 기능

회의실 현황 전체 공개 New

  • 로그인한 모든 사용자가 사이드바 · 모바일 탭의 회의실 현황에서 조회
  • 배치도 + 09~24시 타임라인으로 진행 · 예정 · 종료와 빈 시간 확인
  • 예약자 · 예약명이 함께 표시되는 조회 전용 화면(예약은 공식 시스템에서)
  • 자동 동기화로 하루 5회 최신 상태 유지

요일별 이용 인원 개편 Upd

  • 스탯 레일 — 현재 이용 중 · 하루 평균 · 가장 붐비는/한산한 요일
  • 요일 라벨을 막대에 붙이고 인원은 막대 안에 — 한눈에 비교
  • 오늘 배지와 하루 평균 점선으로 오늘 위치 · 평균 대비를 바로 파악
  • 이용이 있었던 집계 일수를 부제로 표기

회의실 현황 화면 다듬기 Upd

  • 제목 옆 안내 — "멘토링 예약이 없는 회의실을 바로 확인할 수 있습니다"
  • 현황이 없을 때 안내를 역할별로(관리자엔 업로드 안내, 연수생엔 중립 문구)
  • 예약 0건인 날은 종일 이용 가능으로 표시

회의실 현황 이용 안내 Info

  • 갱신 시각은 09 · 12 · 15 · 18 · 21시 — 화면의 기준 시각을 함께 확인
  • 표시되는 예약은 공식 회의실 예약 시스템에 등록된 내용 그대로
  • 회의실 예약 · 변경은 자리요가 아니라 공식 예약 시스템에서

예약 규칙 (현행)

예약 가능 시간08:00 – 20:00 (그 외 시간은 자유 이용)
예약 단위10분 · 1인 1건
기본 이용최대 3시간 (프리셋 30·60·120·180분)
연장종료 1시간 전부터 3시간 1회 (최대 6시간)
자리비움20분 초과 자동취소 · 예약당 2회까지
좌석 반납 / 취소10분 넘게 쓰면 반납, 이내면 취소
재예약 쿨다운같은 자리 20분 (10분 이내 취소는 예외)

운영 메모

✓

✓
자동 동기화는 상시 가동 PC에 의존 — 꺼짐·로그오프·절전 시 중단
✓

✓
